## 📅 Текущее состояние: 16 июня 2026 г.

### Выполненные шаги:
1. **Инициализация проекта**: Создана структура Flutter-приложения с поддержкой GoRouter, Riverpod и EasyLocalization.
2. **База данных**: Развернута схема в Supabase и seed-данные для 4-х клиник Астаны.
3. **Тестирование соединения**:
   * Создан скрипт проверки подключения: [supabase_connection_test.dart](file:///c:/Projects/test/supabase_connection_test.dart).
   * Выявлена и исправлена ошибка 500 (`Database error querying schema`), возникавшая из-за `NULL`-значений в полях `auth.users` после ручного сидинга.
   * **Создан администратор системы**: учетная запись `admin@animora.kz` успешно создана через SQL Editor, авторизация под ней работает и возвращает данные через RLS!
   * **Выявлена проблема с полем `phone` в `auth.users`**: Присутствие номера телефона в `auth.users` без полной сопутствующей конфигурации SMS-провайдеров вызывало внутреннюю ошибку 500 в GoTrue.
   * **Решение**: Исключить `phone` и `is_super_admin` из таблицы `auth.users` при сидинге. Телефонные номера теперь записываются напрямую в таблицу `public.profiles` через SQL UPDATE, что обходит баги GoTrue.
