# 🗺️ Animora: Подробный пошаговый план разработки (Дорожная карта)

Этот документ представляет собой долгосрочную дорожную карту разработки проекта **Animora** от текущего состояния (Phase 0) до выпуска в релиз. Он разбит на логические шаги, каждый из которых содержит детальные инструкции по реализации, настройке и тестированию.

> ℹ️ **Важные ссылки:**
> *   [docs/developer_log.md](file:///c:/Projects/docs/developer_log.md) — Карта проекта, журнал исправленных ошибок и руководства для ИИ-разработчиков.

## 📍 Текущий статус проекта
*   **Фронтенд:** Каркас Flutter-приложения настроен. Реализована навигация (GoRouter), стейт-менеджмент (Riverpod), мультиязычность (RU/KK) и 12 основных экранов для двух интерфейсов (Владелец и Исполнитель). Код полностью очищен от ошибок компиляции.
*   **Бэкенд:** В облачном Supabase развернуты таблицы, настроены политики безопасности RLS и автоматический триггер создания профилей. База данных успешно заполнена (seeded) 4-мя клиниками Астаны. Связь с приложением подтверждена тестами.

## 🚀 ЭТАП 1: Первый запуск и Тестирование MVP (1–2 дня)
Ваша первоочередная задача — запустить приложение и провести полный цикл тест-драйва, чтобы проверить корректность работы базы данных и ролей.

### Шаг 1.1. Запуск приложения
1.  Откройте терминал в IDE и скачайте все пакеты:
    ```bash
    flutter pub get
    ```
2.  Запустите приложение на вашем эмуляторе, телефоне или в браузере (Web-версия):
    ```bash
    flutter run
    ```

### Шаг 1.2. Проведение Тест-Драйва (Сквозной сценарий)
Выполните следующие шаги в интерфейсе запущенного приложения:
1.  **Регистрация владельца:**
    *   Нажмите «Зарегистрироваться» -> введите имя, почту и пароль.
    *   На экране выбора роли нажмите **«Я владелец питомца»** -> «Далее».
2.  **Добавление питомца:**
    *   Перейдите во вкладку *«Питомцы»* -> Нажмите *«Добавить питомца»*.
    *   Введите кличку (например, *«Рекс»*), выберите *«Собака»*, укажите породу и вес -> Сохраните.
    *   Убедитесь, что питомец появился в списке (данные ушли в таблицу `pets`).
3.  **Бронирование услуги:**
    *   Перейдите на *«Главную»* -> выберите категорию *«Ветклиники»*.
    *   Нажмите на карточку клиники **«Любимчик»** -> выберите услугу **«Вакцинация»** -> Нажмите *«Запись»*.
    *   Выберите питомца *«Рекс»*, дату, время (например, *10:00*) -> введите заметку -> Нажмите **«Подтвердить запись»**.
    *   Убедитесь, что запись появилась во вкладке *«Записи»* со статусом **«Ожидает подтверждения»**.
4.  **Смена роли на Исполнителя (Клинику):**
    *   Перейдите в *«Профиль»* -> Нажмите **«Перейти в режим исполнителя»**. 
    *   Интерфейс приложения перестроится на CRM клиники.
5.  **Подтверждение записи в CRM:**
    *   Перейдите на вкладку *«Дашборд»*. В разделе *«Новые заявки»* вы увидите бронирование на Рекса.
    *   Нажмите **«Подтвердить»**. Запись перейдет в раздел *«Активные записи»*.
6.  **Проверка статуса владельцем:**
    *   Вернитесь в *«Профиль»* -> Нажмите **«Перейти в режим владельца»**.
    *   Перейдите во вкладку *«Записи»* -> статус бронирования изменился на **«Подтверждена»**.
7.  *Поздравляем! Базовый флоу MVP работает.*

## ⚡ ЭТАП 2: Локальный n8n и Telegram-вебхуки (2–4 дня)
Настройка системы мгновенных уведомлений для клиник через Telegram, чтобы администраторам не приходилось постоянно держать приложение открытым.

### Шаг 2.1. Локальный запуск n8n
1.  Установите и запустите **Docker Desktop**.
2.  Запустите контейнер n8n через терминал (PowerShell):
    ```bash
    docker run -d --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n n8nio/n8n
    ```
3.  Откройте браузер по адресу `http://localhost:5678` и создайте аккаунт администратора.

### Шаг 2.2. Создание Telegram-бота
1.  В Telegram найдите официального бота **@BotFather**.
2.  Отправьте команду `/newbot`, укажите имя бота (например, `Animora Notification Bot`) и его юзернейм (например, `animora_notif_bot`).
3.  Скопируйте полученный **HTTP API Token** (сохраните его).

### Шаг 2.3. Создание туннеля (ngrok)
Так как облачный Supabase не может отправить вебхук на ваш `localhost:5678`, создайте публичный туннель:
1.  Скачайте и установите **ngrok**.
2.  Запустите туннель в терминале:
    ```bash
    ngrok http 5678
    ```
3.  Скопируйте временный адрес `https://xxxx.ngrok-free.app`.

### Шаг 2.4. Настройка сценария (Workflow) в n8n
1.  В n8n создайте новый workflow:
    *   Добавьте узел **Webhook**. Задайте метод `POST`, а путь — `/supabase-new-booking`.
    *   Скопируйте Production URL вебхука (он будет выглядеть как `https://xxxx.ngrok-free.app/webhook/supabase-new-booking`).
2.  Добавьте узел **Supabase** (или HTTP Request):
    *   Используйте его, чтобы сделать `SELECT` запрос в Supabase и получить по `owner_id`, `pet_id` и `service_id` текстовые имена вместо UUID.
3.  Добавьте узел **Telegram**:
    *   Укажите ваш API Token бота.
    *   В поле `Chat ID` укажите ваш ID в Telegram (его можно узнать через бота `@userinfobot`).
    *   Вставьте текст сообщения, используя данные из предыдущего шага.

### Шаг 2.5. Включение вебхука в Supabase
1.  Зайдите в консоль Supabase -> **Database -> Webhooks**.
2.  Нажмите **Enable Webhooks** -> **Create a new Webhook**.
3.  Настройте триггер:
    *   Name: `notify_new_booking`
    *   Table: `bookings`
    *   Events: `Insert` (только при создании)
    *   Webhook URL: Вставьте ваш скопированный URL из n8n.
4.  Сохраните.
5.  **Тестирование:** Сделайте новую запись в Flutter-приложении. Через 2-3 секунды ваш Telegram-бот должен прислать вам детальное сообщение о новой записи!

## 🗺️ ЭТАП 3: Интеграция Реальных Карт (3–5 дней)
Замена схематичной векторной карты в `home_screen.dart` на настоящую интерактивную карту Астаны.

### Шаг 3.1. Получение API Ключей (Google Maps)
1.  Зайдите в [Google Cloud Console](https://console.cloud.google.com/).
2.  Создайте проект `Animora`.
3.  Включите API: **Maps SDK for Android** и **Maps SDK for iOS**.
4.  Создайте учетные данные (API Keys) и установите ограничения на использование ключа (по пакету приложения `com.animora`).

### Шаг 3.2. Настройка платформ во Flutter
*   **Android:** Откройте [android/app/src/main/AndroidManifest.xml](file:///c:/Projects/android/app/src/main/AndroidManifest.xml) и добавьте внутрь тега `<application>`:
    ```xml
    <meta-data android:name="com.google.android.geo.API_KEY"
               android:value="ВАШ_ANDROID_API_KEY"/>
    ```
*   **iOS:** Откройте [ios/Runner/AppDelegate.swift](file:///c:/Projects/ios/Runner/AppDelegate.swift) и добавьте инициализацию ключа перед `GeneratedPluginRegistrant`:
    ```swift
    import GoogleMaps
    // ... внутри didFinishLaunchingWithOptions
    GMSServices.provideAPIKey("ВАШ_IOS_API_KEY")
    ```

### Шаг 3.3. Изменение UI-кода карты
1.  Откройте [home_screen.dart](file:///c:/Projects/lib/presentation/owner/screens/home_screen.dart).
2.  Импортируйте пакет: `import 'package:google_maps_flutter/google_maps_flutter.dart';`.
3.  Замените метод `_buildInteractiveMockMap` на виджет `GoogleMap`:
    *   Задайте начальную позицию (центр Астаны): `LatLng(51.1605, 71.4704)`.
    *   Генерируйте список `Marker` из данных провайдеров, полученных от `providersAsync.value`.
    *   По клику на маркер (`onTap`) открывайте страницу деталей клиники.

## 🛡️ ЭТАП 4: Расширение функционала (Вторая фаза MVP) (1–2 недели)
Добавление ценности продукту перед выходом на рынок Астаны.

### Шаг 4.1. Автоматический генератор медицинских карт питомцев
1.  Создайте таблицу `health_records` в Supabase для хранения прививок, осмотров и ветеринарных заключений.
2.  Настройте триггер: когда клиника подтверждает запись и меняет статус на `completed` (Завершена), в таблице автоматически создается запись о приеме.
3.  Разработайте экран медкарты во Flutter, где владелец сможет увидеть всю историю лечения и выписанные рецепты в хронологическом порядке.

### Шаг 4.2. Система отзывов и рейтингов
1.  Создайте таблицу `reviews` в Supabase (связь с `bookings`, `profiles` и `providers`).
2.  Во Flutter-интерфейсе Владельца после завершения приема (статус `completed`) показывайте модальное окно: *«Оцените визит в Любимчик от 1 до 5 звезд и оставьте отзыв»*.
3.  Настройте функцию в Supabase (PostgreSQL Trigger), которая при добавлении отзыва автоматически пересчитывает средний рейтинг (`rating`) и количество отзывов (`review_count`) в таблице `providers`.

### Шаг 4.3. Kaspi QR интеграция (Упрощенная)
Полноценный эквайринг Kaspi Pay требует подписания договоров, поэтому для MVP используем гибридный метод:
1.  В профиле исполнителя (`providers`) добавьте поле `kaspi_pay_phone` или ссылку на Kaspi QR.
2.  При оформлении записи или завершении услуги показывайте владельцу питомца кнопку **«Оплатить через Kaspi»**:
    *   Используйте `url_launcher`, чтобы открыть приложение Kaspi с переходом на оплату по номеру телефона клиники или по QR-ссылке: `https://pay.kaspi.kz/...`.
