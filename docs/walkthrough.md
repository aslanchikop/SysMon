## 🚀 Как запустить проект (Инструкция по настройке)

### Шаг 1: Настройка Supabase
1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте новый бесплатный проект.
2. Перейдите в раздел **SQL Editor** в левом меню консоли Supabase.
3. Скопируйте содержимое файла [supabase_schema.sql](file:///c:/Projects/supabase_schema.sql), вставьте его в SQL Editor и нажмите кнопку **Run**.
4. Затем скопируйте содержимое [supabase_seed.sql](file:///c:/Projects/supabase_seed.sql), вставьте в SQL Editor и нажмите **Run** (это наполнит базу тестовыми клиниками и услугами Астаны).

### Шаг 2: Подключение ключей в приложении
1. В консоли Supabase перейдите в **Project Settings -> API**.
2. Скопируйте ваши `Project URL` и `API key (anon public)`.
3. Откройте файл [supabase_config.dart](file:///c:/Projects/lib/core/constants/supabase_config.dart) на вашем ПК и замените заглушки на ваши ключи:
   ```dart
   static const String url = 'ВАШ_PROJECT_URL';
   static const String anonKey = 'ВАШ_ANON_KEY';
   ```

### Шаг 3: Запуск приложения
Убедитесь, что у вас открыт симулятор/эмулятор или подключен телефон, и выполните команды в терминале IDE:
```bash
flutter pub get
flutter run
```
*(Приложение также отлично запустится прямо в браузере как Web-версия).*

## 🧪 Тест-драйв: Сценарий демонстрации (Сквозной флоу)

Чтобы вы могли оценить, как работает приложение, пройдите по этому сценарию:

1. **Регистрация Владельца**: 
   Зарегистрируйте новый аккаунт на экране регистрации -> На экране выбора роли выберите **«Я владелец питомца»**.
2. **Добавление питомца**:
   Зайдите во вкладку *«Питомцы»* -> Нажмите *«Добавить питомца»* -> Введите имя (например, *"Шарик"*), выберите вид *"Собака"* и введите вес -> Нажмите *«Сохранить»*.
3. **Бронирование визита**:
   Перейдите на вкладку *«Главная»* -> Вы увидите карту Астаны с пинами. Нажмите на нижнюю карточку клиники **«Любимчик»** -> В списке услуг нажмите кнопку **«Запись»** напротив *«Вакцинация»* -> Выберите питомца *"Шарик"*, дату и любое время (например, *12:00*) -> Нажмите **«Подтвердить запись»**.
4. **Смена роли (Эмуляция клиники)**:
   Перейдите во вкладку *«Профиль»* -> Нажмите **«Перейти в режим исполнителя»**. Приложение мгновенно перестроит интерфейс на кабинет клиники!
5. **Подтверждение записи клиникой**:
   Войдите во вкладку *«Дашборд»* исполнителя. В разделе *"Новые заявки"* вы увидите заявку от вашего имени на вакцинацию Шарика на выбранное время. Нажмите **«Подтвердить»**. Запись исчезнет из заявок и перейдет в список *"Активные записи"*.
6. **Проверка статуса владельцем**:
   Вернитесь в *«Профиль»* -> Нажмите **«Перейти в режим владельца»** -> Зайдите во вкладку *«Записи»*. Вы увидите, что статус вашей записи изменился на **«Подтверждена»**!
